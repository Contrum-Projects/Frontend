# tienda/

Componentes, hooks y consultas de la tienda pública y la cuenta del cliente, agrupados por área
(una carpeta por área, con sus pruebas al lado). Las páginas de `app/(tienda)/` los importan.

| Carpeta        | Historias                                                                                                          |
| -------------- | ------------------------------------------------------------------------------------------------------------------ |
| `catalogo/`    | Inicio, catálogo, búsqueda, ficha de producto y de pack, precio profesional (SCRUM-106 a 109)                      |
| `carrito/`     | Carrito y carrito del visitante (SCRUM-116, 117, 119)                                                              |
| `compra/`      | Checkout, despacho, factura, pago y resultado (SCRUM-118, 120 a 123, 125)                                          |
| `cuenta/`      | Ingreso, registro, recuperación, mis datos, pedidos, facturación, ofertas (SCRUM-93 a 97, 124, 126, 128, 129, 139) |
| `profesional/` | Verificación y perfil profesional (SCRUM-134, 136, 137)                                                            |
| `diseno/`      | Header, footer y menú de la tienda (con SCRUM-106)                                                                 |

Crea cada carpeta cuando llegue su primera historia.
